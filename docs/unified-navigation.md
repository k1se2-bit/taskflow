# Единые переходы к задаче

Основные списки теперь открывают один экран TaskDetailsPage:

- «Сегодня» — личные задачи и собственные командные назначения.
- «Календарь» — личные и доступные командные задачи.
- Полный личный список — через значок списка на «Сегодня», включая выполненные задачи.
- «Команды» → команда → карточка задачи.

Нажатие на задачу открывает просмотр, смену статуса и личное напоминание. Для изменения полей используется кнопка «Редактировать» внутри карточки. Карандаш владельца в списках команды и календаря остаётся быстрым переходом к редактору. Кнопки создания по-прежнему открывают формы создания, отметка выполнения в личном списке не требует открытия карточки.

Раздел «Уведомления» сохраняет своё специальное действие — нажатие на задачу выбирает время напоминания. Это не обычный список для просмотра задачи. Неиспользуемые ранние оболочки приложения не являются отдельными пользовательскими точками входа; основной запуск остаётся через TodayApp.

## Проверка

1. В полном личном списке откройте активную и выполненную задачи; обе должны открывать карточку.
2. Вернитесь назад и проверьте сохранение поиска и фильтра.
3. Отметьте задачу выполненной непосредственно в списке — карточка не должна открываться от нажатия на отметку.
4. Создайте новую личную задачу кнопкой +; проверьте сохранение.
5. Внутри команды нажмите на карточку своей задачи в аккаунте исполнителя и настройте напоминание.
6. В аккаунте владельца проверьте отдельно нажатие на карточку и на карандаш; первое открывает просмотр, второе — редактор.
7. Убедитесь, что меню статуса в карточке списка не открывает второй экран одновременно.
8. Проверьте доступ к удалению личной задачи через карточку → «Редактировать» → корзина с подтверждением. Удаление командных задач этим обновлением не добавлено.

Правила доступа, схема данных, фильтры, редакторы и механизм уведомлений не изменяются. Копий задач не создаётся. Существующие 56 Flutter-тестов остаются без изменения; отдельных тестов жестов и навигации это обновление не добавляет. Переходы и сборку нужно проверить фактическим прогоном.

Этот документ уточняет старые руководства: для просмотра задачи больше не требуется помнить отдельный маршрут для разных списков. Предыдущие ограничения локальных напоминаний, офлайн-работы и debug APK сохраняются.
