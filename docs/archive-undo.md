# Архив и отмена

Личная задача теперь может быть перемещена в архив без удаления. В карточке личной задачи появилась кнопка «В архив»; для архивной задачи — «Вернуть из архива». В полном личном списке добавлен фильтр «Архив».

## Архив

Архивирование записывает `archived: true` и `archivedAt`; возврат удаляет оба поля обновлением. Документ задачи не удаляется, напоминания и история изменений не стираются. Архивные задачи скрыты из фильтров «Все», «Активные» и «Выполненные», но доступны в «Архиве».

Архивировать может только владелец личной задачи. Для командных задач кнопка архива не добавляется: доступ, статусы и ответственность определяются командными правилами.

## Отмена

После смены статуса в личном списке появляется уведомление с действием «Отменить». Оно возвращает предыдущий статус, который был прочитан перед изменением. После архивирования или возврата в карточке также появляется «Отменить», возвращающее предыдущее значение `archived`.

Отмена доступна, пока открыто соответствующее уведомление. Она не является полной историей изменений и не восстанавливает несколько действий подряд. После закрытия приложения или уведомления отменить последнее действие этим способом нельзя.

## Проверка

1. Откройте личную задачу и нажмите «В архив» — она исчезнет из «Все», «Активные» и «Выполненные».
2. Откройте фильтр «Архив» — задача должна появиться там.
3. Нажмите «Отменить» в уведомлении — задача вернётся в обычные списки.
4. Смените статус задачи в списке и нажмите «Отменить» — предыдущий статус должен вернуться.
5. Проверьте, что командные задачи не получили кнопку архива.
6. Убедитесь, что удаление задачи по-прежнему требует подтверждения и остаётся необратимым.

Схема Firestore расширена необязательными полями `archived` и `archivedAt` только для личных задач. Правила доступа не изменялись: владелец и так может обновлять свой документ. Новые тесты в этом обновлении не добавлялись; существующие 64 теста и ручная проверка остаются обязательными.
