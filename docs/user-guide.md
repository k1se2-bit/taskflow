# Руководство пользователя TaskFlow

## 1. Вход и регистрация

Запустите приложение. На экране входа введите электронную почту и пароль, затем нажмите «Войти». Для нового аккаунта выберите «Нет аккаунта? Зарегистрироваться», заполните поля и нажмите «Зарегистрироваться». При регистрации приложение требует пароль минимум из 6 символов; это минимальная проверка, а не рекомендация использовать короткий пароль.

После входа доступны вкладки «Задачи», «Календарь», «Уведомления» и «Команды». Для выхода откройте вкладку «Задачи» и нажмите значок выхода вверху. При выходе напоминания на текущем устройстве отменяются.

## 2. Личные задачи

1. Откройте «Задачи» и нажмите кнопку +.
2. Введите название, при необходимости описание.
3. Выберите приоритет: «Низкий», «Обычный» или «Высокий».
4. При необходимости нажмите «Выбрать срок». Срок можно убрать кнопкой «Убрать срок».
5. Нажмите «Сохранить».

Название ограничено 200 символами, описание — 5000. Нажмите на задачу для редактирования. Отметка слева переключает выполнение. В редакторе личной задачи значок корзины открывает подтверждение удаления; восстановления в интерфейсе нет.

Поле поиска ищет по названию и описанию. Фильтры «Все», «Активные» и «Выполненные» изменяют отображаемый список. Личные задачи не становятся командными автоматически и не передаются другим участникам.

## 3. Создание команды и вступление

### Владелец

1. Откройте «Команды» и нажмите кнопку создания команды.
2. Введите название и нажмите «Создать».
3. Откройте созданную команду.
4. Нажмите «Скопировать ID для заявки» и передайте ID нужному человеку.

ID сам по себе не даёт доступа. При появлении заявки проверьте имя и UID заявителя, затем нажмите «Принять» либо «Отклонить» и подтвердите действие. Имя в заявке указано самим заявителем и не является подтверждением личности.

### Участник

1. Во вкладке «Команды» раскройте «Подать заявку в команду».
2. Вставьте ID команды из 20 символов и укажите имя для заявки.
3. Нажмите «Отправить заявку».
4. После одобрения владельцем команда появится в списке после синхронизации.

### Имена

Владелец может нажать карандаш у участника и сохранить отображаемое имя длиной до 80 символов. Оно действует только в этой команде. Аккаунт, UID и назначенные задачи не меняются. При совпадении имён в выборе исполнителя добавляется сокращённый UID.

## 4. Командные задачи

Владелец открывает команду и нажимает «Назначить задачу». Нужно указать название, описание при необходимости, исполнителя и необязательный срок. После нажатия «Назначить» задача появляется в команде.

Статусы: «Новая», «В работе», «Выполнена». Статус меняется через меню в карточке. Владелец видит все задачи команды и может редактировать их карандашом, включая переназначение. Участник видит только свои назначения и меняет только статус. Удаление командных задач пока недоступно.

### Поиск, фильтры и сводка

- Поиск работает по названию и описанию без учёта регистра.
- Можно выбрать статус; владелец также выбирает исполнителя.
- «Только просроченные» показывает незавершённые задачи со сроком раньше сегодняшнего дня. Задача на сегодня не считается просроченной.
- «Сбросить фильтры» очищает поиск и ограничения списка.
- Сводка и прогресс считаются до применения фильтров, по всем доступным пользователю задачам. «Показано» относится к отфильтрованному списку.

## 5. Календарь

1. Откройте «Календарь».
2. Выберите «Личные» или «Командные». Во втором случае выберите команду.
3. Укажите день в календаре и прокрутите к задачам.
4. При необходимости используйте фильтры «Все», «Активные», «Выполненные».

Переключатель «Все просроченные» показывает просроченные незавершённые задачи независимо от выбранного дня. Выбор даты или кнопка «Сегодня» возвращает просмотр по дню. Задачи без срока в календарь не включаются.

Нажатие на командную задачу открывает описание. Статус можно изменить в карточке. Карандаш редактирования доступен владельцу. Личная задача открывается в своём редакторе.

## 6. Напоминания

1. Откройте «Уведомления» и нажмите «Разрешить и проверить».
2. При запросе Android разрешите уведомления. Должно появиться тестовое уведомление.
3. Выберите «Личные» либо «Командные». Для командных раскройте нужную команду.
4. Нажмите на активную задачу и выберите дату и время в будущем.
5. Убедитесь, что время сохранилось под задачей.

В командном режиме доступны только назначения текущего пользователя, даже если он владелец команды. Время напоминания хранится в личных настройках исполнителя и не назначается за другого человека. Для отмены нажмите значок перечёркнутого будильника.

Счётчик «Ожидают показа на этом устройстве» берётся из очереди плагина уведомлений. Он обновляется после планирования, при возвращении в приложение, кнопкой обновления и периодически, пока приложение активно. Уведомления, уже находящиеся в шторке, и ожидающие уведомления — разные категории.

Надпись «время прошло» означает только наступление выбранного времени, а не подтверждённую доставку. Android может задерживать показ. Выполнение, переназначение и потеря доступа учитываются после синхронизации; на отключённом или закрытом устройстве старое напоминание ещё может сработать. В этой версии нет серверного push о назначении новой задачи.

## 7. Если что-то не отображается

Сначала проверьте аккаунт, выбранную команду, дату срока и включённые фильтры. При ошибке доступа не ослабляйте правила Firebase: сообщите разработчику текст ошибки. Если напоминание не приходит, используйте тестовую кнопку и проверьте разрешение уведомлений. Не публикуйте пароль, Firebase-конфиги и ключи сервисных аккаунтов в сообщении об ошибке.

Получение APK описано в [инструкции по сборке](android-apk.md).
