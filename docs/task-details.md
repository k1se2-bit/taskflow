# Карточка задачи: просмотр и личное напоминание

Нажатие на личную или командную задачу на экране «Сегодня» теперь открывает общий экран «Задача». В нём доступны описание, источник, срок, статус и личное напоминание. Приоритет отображается для личной задачи. Данные задачи и команды обновляются подписками; при потере доступа или смене аккаунта интерфейс закрывает доступ к содержимому. Это не заменяет серверные правила Firestore.

## Права

- Владелец личной задачи может редактировать её, менять статус и настраивать напоминание.
- Владелец команды может редактировать поля задачи и менять статус.
- Исполнитель командной задачи может менять статус и настраивать только своё напоминание.
- Владелец команды не задаёт напоминание за другого исполнителя.

Для редактирования используются прежние проверяемые формы. Карточка не добавляет новый способ удаления командных задач. Настройка командного напоминания сохраняется в существующем личном документе пользователя; общая задача не получает чужое время напоминания. Схема данных и правила доступа в этом обновлении не меняются.

## Проверка

1. На «Сегодня» откройте личную задачу, измените статус, перейдите в редактор и вернитесь.
2. В карточке нажмите «Напомнить мне», выберите будущее время и убедитесь, что оно появилось также во вкладке «Уведомления».
3. Отмените напоминание и проверьте обновление настройки.
4. Повторите для своей командной задачи в аккаунте исполнителя. У него не должно быть кнопки редактирования полей.
5. Оставьте карточку открытой на втором эмуляторе и переназначьте задачу владельцем: после синхронизации прежний исполнитель должен потерять доступ.
6. Отметьте задачу выполненной: новое напоминание для неё недоступно, открытая карточка остаётся видимой до возврата в список.

Добавлены 10 тестов функций доступности действий. Они проверяют только логику интерфейса, а не реальные серверные разрешения и доставку уведомлений. Автоматический прогон и ручную проверку после коммита нужно подтвердить отдельно.

## Ограничения этапа

Новая карточка пока подключена только к переходам из «Сегодня». Календарь, полный личный список и раздел команды пока используют прежние переходы. Перевод остальных точек входа должен выполняться отдельным согласованным обновлением. Старое описание краткого просмотра в docs/today.md для переходов из «Сегодня» заменяется этим документом.

Выбор напоминания требует проверки актуальной задачи на сервере: при отсутствии сети настройка не сохраняется как будто она подтверждена. Между проверкой и сохранением назначение может измениться; планировщик дополнительно проверяет текущие назначения после синхронизации. Мгновенная отмена уведомления на закрытом или офлайн-устройстве не гарантируется.

Поддерживаются существующие локальные уведомления, а не серверные push. Архив, черновики, общий новый редактор полей и отмена изменений в этот этап не входят.
