## Реализованные функции

| Область | Возможности |
| --- | --- |
| Аккаунт | Регистрация и вход по электронной почте и паролю, выход |
| Личные задачи | Создание, редактирование, удаление с подтверждением, срок, приоритет, выполнение, поиск и фильтры |
| Команды | Создание, заявка по ID, принятие и отклонение заявки владельцем, список участников |
| Имена | Владелец меняет отображаемое имя участника внутри команды, UID остаётся постоянным |
| Командные задачи | Владелец создаёт, редактирует и переназначает задачи; исполнитель меняет статус своей задачи |
| Поиск и сводка | Поиск по названию и описанию, фильтры статуса, исполнителя и просрочки, сводка и прогресс |
| Календарь | Личные и командные режимы, выбор команды, задачи на дату, статусы и просрочка |
| Напоминания | Локальные уведомления, личное время напоминания для своей командной задачи, отмена, счётчик ожидающих показов |
| Проверки | Flutter-анализ, Flutter-тесты, отдельные тесты правил на Firestore Emulator |
| Сборка | Ручной workflow debug APK в GitHub Actions |

Участник получает только назначенные ему командные задачи. Владелец получает все задачи своей команды. Сводка использует доступные пользователю задачи до применения экранных фильтров. Просрочка означает незавершённую задачу со сроком раньше текущего календарного дня по часам устройства.

## Ограничения

1. Используются локальные уведомления, а не серверные push о назначении задачи. Android может задерживать неточный показ.
2. Выполнение, переназначение и потеря доступа учитываются после синхронизации. На закрытом либо отключённом от сети устройстве ранее запланированное уведомление может ещё сработать.
3. Время командного напоминания — настройка самого исполнителя. Владелец не задаёт время за другого пользователя. При переназначении настройка прежнего исполнителя не переносится новому.
4. При выходе из аккаунта локальные уведомления отменяются. Смена аккаунта на одном эмуляторе не заменяет проверку отмены при переназначении на двух устройствах.
5. Задачи без срока не отображаются в календаре; они доступны в основном списке задач или внутри команды.
6. Удаление командных задач запрещено в текущей версии. Не следует путать его с удалением личных задач.
7. Лимит команды по текущим правилам — 50 участников, включая владельца.
8. Нет пользовательского интерфейса удаления участников, передачи владения и удаления команды.
9. APK из workflow подписывается debug-ключом. Совместимость обновления с другими сборками и постоянная подпись не обеспечены. Это не готовый релиз Google Play.
10. Тесты правил используют файл из репозитория. Они не подтверждают автоматически, что та же версия правил опубликована в рабочем Firebase-проекте.
11. Полноценная проверка работы без сети, смены часового пояса, перезагрузки устройства и ограничений батареи пока не оформлена.
